# Product / MoSCoW Delta v1.1 — 공식 바다낚시지수

**Date**: 2026-09-16  
**Authority**: 사용자의 v1.1 변경 승인  
**Baseline preserved**: FR-01~05와 기존 Requirement ID의 의미·우선순위는 변경하지 않는다.

## PRD 비교 결과

기존 PRD는 포인트 조회(FR-01), 판단 브리프(FR-02), 신뢰상태(FR-04)를 Must로 두지만,
어종별 공식 바다낚시지수를 독립 제품 기능으로 정의하지 않았다. 또한 미지원 위치에서 예상어종을
만드는 행위를 Out of Scope로 두고 정확 GPS 저장을 금지했다. v1.1은 이 경계를 유지하면서,
사용자가 선택한 공식 지원 포인트에 한해 국립해양조사원의 공식 결과를 별도 섹션으로 제공한다.

## 신규 Must 범위

- **FR-06 / Must — 공식 바다낚시지수**: 공식 지원 포인트를 사용자가 명시적으로 선택한 경우에만
  공식 어종·등급·점수·예측시각과 제공된 환경 필드를 출처/신뢰상태와 함께 표시한다.
- **FR-07 / Must — 현재 위치로 공식 후보 찾기**: 사용자 행동 후 일회성 위치권한을 요청하고,
  주변 공식 포인트 후보와 거리를 보여주되 자동 선택하지 않는다.
- **FR-08 / Must — live 데이터 보안 경계**: provider key는 브라우저 bundle/query/log에 포함하지
  않으며 live 모드는 승인된 server-side secret boundary를 통해서만 활성화한다.

## 유지되는 Out of Scope

- 자체 조과확률·추천·안전·법적 허용 판정
- 미지원 좌표의 예상어종 또는 내부 점수 생성
- 공식 점수 재계산, GPS 자동매핑, 정확 좌표 영구저장/분석 로그
- `ENVIRONMENT_BASED_GUIDANCE` 사용자 결과 생성

## 출시 경계

제품 UI, 타입, 공식 스키마 parser 경계, demo provider, GPS 후보/확인, 실패·stale 테스트는 구현한다.
공공데이터포털 service key와 serverless 운영 계정이 없으므로 live proxy 선택·배포는
`LIVE_API_MANUAL_CONFIGURATION_REQUIRED`로 남긴다. Cloudflare/Vercel/Netlify 중 하나를 임의
선택하지 않으며, 계정·비용·secret 운영 승인을 받은 뒤 ADR로 결정한다.
