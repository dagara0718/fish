## Before

The deployed screen read as a test harness: large marketing-style hero, internal prototype labels, fixture
explanation as primary content, a developer-rule sidebar, QA scenario strings in first-use suggestions and a
flat slot table without a strong decision-brief hierarchy.

## Result

The refactor uses a 64px product header, compact search surface, 320px discovery rail, flexible brief workspace,
polished candidate rows, strong identity/availability hierarchy, responsive information cards and a separate
official species/environment section. Demo provenance is one small header disclosure; QA scenarios are in a
secondary details element. Mobile uses a true serial layout and full-width evidence sheet.
