## CRITICAL / HIGH

None remaining. One HIGH found and fixed in the uncommitted draft before this pass closed:

- **HIGH (fixed) — unsourced time basis.** The draft built the request window with `getUTC*` and
  justified it as "more conservative", contradicting its own `timeBasis: 'UNCONFIRMED'` contract. If
  KHOA is KST, the app would have shown a window 9 h in the past as the current forecast. Replaced by
  `requestWindow()` (covers the present under both readings) and a UI that never names a "now" row.
- **MEDIUM (fixed)** — the panel returned `null` for `NOT_CONNECTED` and swallowed exceptions, so a
  misconfigured deploy looked identical to "no feature". Now finite text states.
- **MEDIUM (fixed)** — marine shared the index `AbortController`, so a cancelled marine request could
  leave `marineBusy` true and a marine retry would have cancelled the index. Now separate controllers.
- **LOW (fixed)** — `전류` was mapped to `INSTANTANEOUS`; live data shows it is the current's turn.
