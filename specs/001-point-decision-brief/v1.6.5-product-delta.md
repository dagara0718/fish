# v1.6.5 product delta — spot brief for the user's own location

Baseline: `4ef9a25`. User direction (2026-09-27): after a map click or "현재 위치 사용", show the
species picture for **that spot** directly — using nearby official points, water temperature and tidal
current, for the chosen day — instead of asking the user to pick an official point.

## Requirement changes (user-approved)

- `REQ-FUNC-NEARBY-001` (explicit button) is **superseded** by `REQ-FUNC-SPOT-001`: the brief loads
  automatically after the map click / GPS fix. It still never auto-selects an official point; the
  selected-point brief still needs "이 포인트 선택".
- The v1.3 rule "an arbitrary map click does not call the per-point index API" is superseded by the
  same decision; the call count is bounded (≤ 3 points within 15 km).

## New requirements

- `REQ-FUNC-SPOT-001` (automatic, bounded): map click or GPS fix → catalog → official points within
  15 km (≤ 5 listed, ≤ 3 looked up) → brief. Any navigation or unmount cancels it.
- `REQ-FUNC-SPOT-002` (expected species): environment-based species guidance (existing scoring policy,
  water temperature + season from KHOA forecast) computed from the **nearest** successfully loaded
  official point, for the selected forecast slot, labelled with that point's name and distance and
  "not the spot's measured temperature". No interpolation between points.
- `REQ-FUNC-SPOT-003` (nearby official grades): REQ-FUNC-NEARBY-002~004 comparison, shown in the brief.
- `REQ-FUNC-SPOT-004` (tidal current): map click → forecast at the clicked location; GPS fix →
  forecast at the nearest official point's public coordinate, stated in the UI; the GPS fix itself is
  never sent to any backend (it stays in component memory for local distance only).
- `REQ-FUNC-SPOT-005` (day): a date selector over the forecast slots present in the official data
  switches both the expected species and the official grades. The tidal forecast stays on the current
  time window (its time basis is still TBD, REQ-FUNC-MARINE-UI-005).
- Official points remain reachable via "주변 공식 포인트 직접 보기" → preview → "이 포인트 선택".

## Known limit (not hidden)

Species guidance is only as strong as the cited evidence: since the v1.5 evidence audit only 참돔 has
a cited water-temperature threshold, so the other five species show "판단 근거 부족", and
CURRENT_SPEED/CURRENT_DIRECTION stay UNKNOWN for all (REQ-FUNC-GUIDANCE-007). Improving this needs
new cited species evidence, not more code.
