## Live catalog and time policy
No synthetic points enter live. Explicit search/catalog load requests a bounded paginated official catalog for selected gubun (up to 20 pages, 300/page); oversized/incomplete catalogs return an error, not false completeness. GPS only ranks already loaded points. Catalog lookup is distinct from selected-point index fetch.
No production freshness threshold is invented: a prediction date before today's Asia/Seoul calendar date is STALE; otherwise UNVERIFIED pending publication/freshness verification. Missing prediction date/session remains UNVERIFIED; cache fallback always STALE except existing CONFLICT/failed states stay distinct. Do not reinterpret forecast as current observation.
Environment units absent from retrieved Swagger remain unspecified ("단위 미확인") until guide evidence; do not guess m/s.
Proxy timeout (10s), transport cache (5min), pagination cap and quota limits are operational controls, not data freshness policy.
