# v1.6.4 product delta — nearby official-point comparison; Worker marine 422

Baseline: `d8bb98d` (v1.6.3 complete). No existing Requirement ID changes meaning.

## User request and decision (2026-09-27)

After an arbitrary map click the app lists the nearest official points and the user picks one, so
the data shown is for a different location — the user found that low-trust and asked for "species
likely to appear, compared across nearby points". Decision (user-confirmed): **no probability**.
The official index is a per-point "낚시 여건" grade, not a species-occurrence or catch probability,
and the clicked location has no official value; averaging or interpolating neighbours into a
probability would fabricate evidence (constitution III/IV; existing species-guidance e2e F forbids
probability/recommendation wording). Instead: an on-request, clearly-labelled comparison of the
nearest official points' own grades.

## New requirements

- `REQ-FUNC-NEARBY-001` (explicit trigger, bounded cost): after an arbitrary map click, the nearest
  list offers "주변 N곳 공식 지수 비교" (N = min(3, candidates)). Only that press fetches per-point
  official data (at most 3 lookups); the click alone still fetches nothing per point. Any navigation
  or unmount cancels it; a superseded comparison never renders.
- `REQ-FUNC-NEARBY-002` (honest framing): the panel states it is not the clicked location's value and
  not a species-occurrence/catch probability; it never scores, weights, interpolates, averages or
  ranks points or species. Species are listed alphabetically; per species it shows only counts of
  KHOA's own grades ("좋음 2곳 · 보통 1곳").
- `REQ-FUNC-NEARBY-003` (like-for-like): only records at one shared forecast slot (the earliest slot
  any compared point has) are compared, and the slot is displayed. A point with no record for a
  species is "값 없음", never a grade; a point whose lookup failed is "확인 실패" and is excluded from
  the counts, while the other points still render (partial-failure-first).
- `REQ-FUNC-NEARBY-004` (provenance): TrustBadge per cell and the set of statuses at section level,
  source, distance per point, and a keyboard-operable per-point evidence table. Choosing a point
  still goes through the existing explicit preview → "이 포인트 선택" flow.
- `REQ-FUNC-MARINE-UI-008` extended to the Cloudflare Worker's `/api/marine-current` (same shared
  `isNoSearchData`/`validRange`; 422 not cached).
